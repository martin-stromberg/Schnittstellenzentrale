# Playwright-Tests

Die Playwright-Testinfrastruktur ergänzt das Testprojekt `Schnittstellenzentrale.Tests` um End-to-End-UI-Tests. Sie prüft die wichtigsten Benutzerabläufe in einem echten Chromium-Browser und trägt zusammen mit gezielten bUnit-Tests zur Stabilisierung des Coverage-Gates mit 70 % Line Coverage bei.
